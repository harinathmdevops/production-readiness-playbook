# Data Migration Framework: Swiss MariaDB (Prod) to German Azure VM (Non-Prod)

This repository provides a step-by-step framework to securely and efficiently migrate an **800 GB MariaDB instance** from a Swiss production environment (On-Premises or Azure Cloud) to a Non-Production Azure Linux VM in Germany. It includes instructions for multi-threaded performance tuning, secure network bridging, and native SQL data anonymization to maintain compliance with the **Swiss Federal Act on Data Protection (FADP)** and **EU GDPR**.
